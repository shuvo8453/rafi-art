IMROOZ SHIMU — PROFESSIONAL ARTIST WEBSITE
==========================================

This is a complete static website. No WordPress, database, npm install, or build step is required.

FILES
-----
index.html        Main website page
styles.css        Responsive professional styling
script.js         Mobile menu, artwork filtering, lightbox and scroll effects
assets/images/    Optimised artist photograph and 13 portfolio artworks
assets/docs/      Downloadable artist profile & portfolio PDF
assets/favicon.svg Browser icon

HOW TO UPLOAD
-------------
1. Unzip the website package on your computer.
2. Upload the CONTENTS of the folder (index.html, styles.css, script.js and the assets folder) into your website's public web directory, usually public_html, www, htdocs or the root folder provided by your host.
3. Keep the folder structure exactly as supplied.
4. Open your domain in a browser. The website will load immediately.

The site is responsive for desktop, tablet and mobile and does not rely on external fonts, libraries or CDNs.
